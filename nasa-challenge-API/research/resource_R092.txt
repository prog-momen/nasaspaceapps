Note about LRO Ephemeris Data
There are two sources 
									of LRO ephemeris data (SPICE SPK kernels). 
									SPK data from the LRO Flight Dynamics Team 
									(FDT) are available from the PDS Navigation 
									and Ancillary Information Facility (
NAIF
). 
									The FDT SPK data are currently produced 
									without using LRO Lunar Orbiting Laser 
									Altimeter (LOLA) data.
LRO SPK data produced 
									by the LOLA team are available from the
Radio Science Data Archive at the LOLA Data 
									Node
in the DATA/SPK directory.
The LOLA SPK files are 
									orbit reconstructions produced by the LOLA 
									Precise Orbit Determination Team.
These SPKs are used for geolocation 
									of LOLA data. They contain spacecraft 
									ephemerides and have the same binary format 
									as SPK files provided by NAIF. More 
									information about the content of the LOLA 
									SPK data may be found in the "GEODYN 
									Trajectory Files (SPK Directory)" 
									information in the "Secondary Data" 
									section of the
Radio Science Data Set catalog file
.
