Mission Characteristics
Lifetime:
2025 - 2027 (planned)
Wavelength:
0.75-1.1 microns, R=39
1.1-1.6 microns, R=41
1.6-2.4 microns, R=41
2.4-3.8 microns, R=35
3.8-4.4 microns, R=112
4.4-5.0 microns, R=128
Area Coverage (planned):
100% of sky
Instruments:
Wide Field Linear Variable Filter (LVF) Imaging Spectrograph

NASA
Contributing Institutions:

Moving Object Search Tool (MOST)
Determine the orbit for a given solar system object then find SPHEREx images that covered the object's predicted positions at their observation epochs.
SPHEREx Science Tools
Spectrophotometry Tool
Extract spectra from SPHEREx Spectral Images using forced photometry. Read the
Spectrophotometry Tool documentation
for detailed usage instructions, inputs, and outputs.
Mosaic Tool
Create custom multiwavelength mosaics from SPHEREx Spectral Images.
Cutout Tool
Extract spatial subsets from SPHEREx Spectral Image Multi-Extension FITS files.
Source Discovery Tool
Identify and characterize significant detected sources within a user defined region using SPHEREx data alone, without requiring positional priors.
