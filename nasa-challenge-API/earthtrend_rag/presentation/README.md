# حزمة العرض — توقع خطر الحرائق لشهر قادم

هذا المجلد لكل ما يخص العرض والشرح، ومفصول عن الكود عمدًا.

| الملف | الغرض |
|---|---|
| `01_recommendations.md` | توصيات تجهيز البروتوتايب للعرض (ما نفعله وما لا نفعله) |
| `02_demo_script.md` | سيناريو عرض ثابت: 4 أسئلة بالترتيب، وما يُقال عند كل واحد |
| `03_explainer.md` | شرح مبسط للمصدرين والمنهج والحدود (يصلح كشريحة أو صفحة) |
| `04_judges_qa.md` | أسئلة متوقعة من اللجنة وأجوبة صادقة |
| `05_pre_demo_checklist.md` | قائمة فحص قبل العرض بدقائق |

## قاعدة واحدة تحكم كل شيء
المنتج **توقع خطر رسمي مبني على نموذج**، وليس احتمال حريق، وليس توقعًا يوميًا، ومهارته المحلية **لم يتحقق منها هذا التطبيق**. أي جملة في العرض تخالف هذا يجب حذفها.
